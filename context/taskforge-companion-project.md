**Architecture (Wave 0 built 2026-06-10, verified):**
- `core/registry/` — `ChapterMeta` (eager metadata, currently 27 roadmap chapters) + `loadContent()` lazy import per ready chapter → `ChapterContent { steps, quiz, proveIt, exercise }`. `StepDef = { id, title, blocks: ContentBlock[], panel: PanelDef }`. Routes/sidebar/home/search/progress all derive from `WAVES`.
- Panels: `code` (manifest file + `region` slice + `diff` gutter) / `code-inline` / `diagram` (mermaid lazy via dynamic import, theme-aware re-render) / `filetree` / `simulator` (DemoScenario req/res) / `live-demo` (NgComponentOutlet) / `app-tree` (cumulative snapshot explorer). `panel-host` dispatches via cast helpers (strictTemplates).
- `chapter-page` = scrolly engine: IntersectionObserver `-45%` band, panels crossfade abs-positioned, render-window `renderedUpTo` (lazy panels, keep-alive), step rail ≥1460px, fragment deep-links (`#step-0.5` — search/glossary jump + activate), `markStepSeen` per activation. Narrow ≤900px → inline panels, no stage (data-driven, not reparenting).
- `reference/chNN/` overlay model = ONLY files created/changed per chapter; `tools/materialize-snapshots.mjs` (overlay+CLI), `generate-guide-manifest.mjs` (regions from `#region` markers, **LCS changedLines diff**, status added/mod) → `guide-manifest.generated.ts` (committed, regenerated on start/build). `verify:snapshots` (milestones.json → dotnet/ng build), `verify:coverage` (every final-snapshot path must appear as literal in `src/app/chapters/**` — "no file by magic"). Snapshots start at ch01; `reference/milestones.json` must be created when ch01 lands (script FAILS if chapters exist with empty milestones).
- Progress/Theme/Search/ContentIndex services in `core/state/`. localStorage keys `taskforge-companion-progress` / `-theme`.

**Per-chapter build loop (1 chapter/session):** (a) extend `reference/chNN/` + milestones → `pnpm verify:snapshots` green; (b) author `src/app/chapters/chNN-*/content.ts` + flip registry meta to `ready` (+`loadContent`); (c) `pnpm verify:coverage`; (d) preview checks: 0 console errors, steps===panels, arrow-scan via TreeWalker (skip `pre/code/.ltr/svg`), quiz/prove-it present.
